UserStats certificate chain support added on 2026-05-16. `Client` now stores the peer TLS certificate chain as `Vec<rustls::pki_types::CertificateDer<'static>>` from `tls_connection.peer_certificates()` and exposes `get_certificate_chain()`. `messages::encoder::UserStats.certificates` changed from `Vec<bytes::Bytes>` to `Vec<CertificateDer<'static>>`; encoder converts native certs to protobuf `bytes::Bytes`, and decoder converts protobuf bytes back to `CertificateDer` via `to_vec()`. `build_user_stats_payload` includes target cert chain when `stats_only == false`, and keeps it empty for stats-only responses. Added integration test `integration_tests::scenarios::user_stats::user_stats_includes_certificate_chain`. Verification: `cargo fmt`, `cargo test user_stats_includes_certificate_chain`, and `cargo test user_stats` passed.
