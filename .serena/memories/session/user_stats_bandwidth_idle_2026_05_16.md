Implemented UserStats bandwidth and idle tracking on 2026-05-16. `ClientStats` now records TCP/UDP packet counts and byte volume using existing dormant fields. `Client::read_proto_message`, `write_proto_message`, and `write_proto_message_batch` account successful TCP frames (6-byte header + encoded payload); batch writes count each frame. The UDP process loop accounts successfully matched/decrypted UDP datagrams and touches activity. `Client::idle_duration()` uses `last_active`; inbound message handlers call `client.touch_activity()` after handler completion, so a UserStats request reports idle time leading into the request. `build_user_stats_payload` now reports `bandwidth` as average bits/sec over online duration from total tracked volume, and `idlesecs` from idle duration. Added `user_stats_reports_bandwidth_and_idle_time` integration test.
