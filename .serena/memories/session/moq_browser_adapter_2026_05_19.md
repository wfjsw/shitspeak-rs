Continued MoQ transport work on 2026-05-19. Added a real default browser MoQ SDK adapter in `web/sdk/shitspeak.js` behind dynamic module loading (`@moq/lite@0.2.3` and `@moq/hang@0.2.5` via esm.sh by default, injectable via `moqLiteModule`/`moqHangModule` or global `ShitSpeakMoqModules`). Adapter publishes `web/moq` with `control/up` and `audio/up/mic`, consumes server `web/moq`, reads `control/down`, `catalog.json`, and fixed `audio/down/slot/{n}` tracks, sends JSON commands, tracks `voice_control_ack` before emitting mic packets, encodes mic Opus with WebCodecs `AudioEncoder`, Hang legacy frames for normal mic packets, and SSMA frames for terminators, and decodes speaker Opus with WebCodecs `AudioDecoder` into WebAudio/MediaStream output. Extended SDK types and fake MoQ tests for module injection and track wiring. Server-side `MoqSessionRuntime::handle_inbound_audio_frame` now accepts terminator frames after PTT-off ack so browser terminators are not dropped when control wins the race; added Rust test `inbound_audio_accepts_terminator_after_ptt_off_ack`.
